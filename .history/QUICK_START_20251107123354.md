# Quick Start Implementation Guide

## Step-by-Step Setup Instructions

### Prerequisites Check

Before starting, ensure you have:
- [ ] Node.js 18+ installed (`node --version`)
- [ ] npm or pnpm installed
- [ ] Git installed
- [ ] A code editor (VS Code recommended)
- [ ] PostgreSQL database access (or ready to create one)

### Phase 1: Project Initialization (30 minutes)

#### Step 1: Create Next.js Project

```bash
# Navigate to your project directory
cd /Users/elizabethstein/Projects/flolabsinternational

# Create Next.js app with TypeScript and Tailwind
npx create-next-app@latest . --typescript --tailwind --app --no-src-dir --import-alias "@/*"

# Answer prompts:
# ✔ Would you like to use ESLint? Yes
# ✔ Would you like to use Turbopack? No
# ✔ Use experimental React Compiler? No
```

#### Step 2: Install Payload CMS

```bash
# Install Payload and required dependencies
npm install payload @payloadcms/db-postgres @payloadcms/richtext-lexical @payloadcms/next

# Install additional required packages
npm install sharp cross-env dotenv
```

#### Step 3: Install UI and Form Libraries

```bash
# Install shadcn/ui (optional but recommended)
npx shadcn-ui@latest init

# Install form handling
npm install react-hook-form zod @hookform/resolvers

# Install animation library (optional)
npm install framer-motion
```

### Phase 2: Database Setup (15 minutes)

#### Option A: Local PostgreSQL

```bash
# Install PostgreSQL (if not already installed)
# macOS:
brew install postgresql@16
brew services start postgresql@16

# Create database
createdb flolabs
```

#### Option B: Supabase (Cloud)

1. Go to https://supabase.com
2. Create new project
3. Wait for database to provision
4. Copy connection string from Settings > Database

#### Option C: Vercel Postgres

```bash
# Install Vercel CLI
npm i -g vercel

# Login to Vercel
vercel login

# Create Postgres database
vercel postgres create flolabs-db
```

### Phase 3: Configure Payload CMS (30 minutes)

#### Step 1: Create Environment Variables

Create `.env.local`:

```env
# Database
DATABASE_URI=postgresql://localhost/flolabs
# Or use your Supabase/Vercel connection string

# Payload CMS
PAYLOAD_SECRET=your-32-character-secret-key-here
PAYLOAD_PUBLIC_SERVER_URL=http://localhost:3000

# Optional: External integrations
# APPLICATION_API_URL=
# APPLICATION_API_KEY=
```

Generate a secure secret:
```bash
openssl rand -base64 32
```

#### Step 2: Create Payload Config

Create `payload.config.ts` in project root:

```typescript
import { buildConfig } from 'payload/config'
import { postgresAdapter } from '@payloadcms/db-postgres'
import { lexicalEditor } from '@payloadcms/richtext-lexical'
import path from 'path'

export default buildConfig({
  serverURL: process.env.PAYLOAD_PUBLIC_SERVER_URL || 'http://localhost:3000',
  
  admin: {
    user: 'users',
  },
  
  editor: lexicalEditor({}),
  
  collections: [
    // We'll add collections here
  ],
  
  db: postgresAdapter({
    pool: {
      connectionString: process.env.DATABASE_URI,
    },
  }),
  
  typescript: {
    outputFile: path.resolve(__dirname, 'payload-types.ts'),
  },
})
```

#### Step 3: Create First Collection (Users)

Create `src/collections/Users.ts`:

```typescript
import { CollectionConfig } from 'payload/types'

export const Users: CollectionConfig = {
  slug: 'users',
  auth: true,
  admin: {
    useAsTitle: 'email',
  },
  fields: [
    {
      name: 'name',
      type: 'text',
      required: true,
    },
    {
      name: 'role',
      type: 'select',
      options: [
        { label: 'Admin', value: 'admin' },
        { label: 'Editor', value: 'editor' },
      ],
      defaultValue: 'editor',
      required: true,
    },
  ],
}
```

Update `payload.config.ts` to include Users collection:

```typescript
import { Users } from './src/collections/Users'

export default buildConfig({
  // ... previous config
  collections: [Users],
  // ...
})
```

### Phase 5: First Run (10 minutes)

#### Step 1: Initialize Database

```bash
# Run migrations
npm run payload migrate

# Generate TypeScript types
npm run generate:types
```

#### Step 2: Create Admin User

```bash
npm run payload create-first-user
```

Follow prompts to create your admin account.

#### Step 3: Start Development Server

```bash
npm run dev
```

Visit:
- Frontend: http://localhost:3000
- Admin Panel: http://localhost:3000/admin

## Troubleshooting Common Issues

### Issue: Database connection error

**Solution**: Check your `DATABASE_URI` in `.env.local` is correct

### Issue: Payload admin not loading

**Solution**: 
- Make sure you created the admin route correctly
- Check console for errors
- Verify `PAYLOAD_SECRET` is set

### Issue: TypeScript errors

**Solution**:
```bash
npm run generate:types
```

### Issue: Sharp/image optimization errors

**Solution**:
```bash
npm rebuild sharp
```
