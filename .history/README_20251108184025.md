# Flo Labs International - Modern Website

> Modern, high-performance website built with Next.js 16 and Strapi CMS

## 📋 Project Overview

A complete redesign of flolabs.international, moving from WordPress to a modern JAMstack architecture using Next.js 16, Strapi v5 (headless CMS), and PostgreSQL.

**Live Site:** https://flolabsfrontend.vercel.app  
**CMS Admin:** https://strapi-production-7ecb.up.railway.app/admin  
**Original Site:** https://flomad.international (WordPress)

## 🛠 Technology Stack

### Frontend
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion (optional)
- **Forms:** React Hook Form + Zod validation

### Backend & CMS
- **CMS:** Strapi (self-hosted, open-source headless CMS)
- **Database:** PostgreSQL (included with Strapi hosting)
- **API:** Next.js API Routes + Strapi's REST/GraphQL APIs

### Hosting & Deployment
- **Frontend Hosting:** Vercel (free tier)
- **CMS Hosting:** Railway, DigitalOcean, or Render
- **Database:** PostgreSQL (included with CMS hosting)
- **Media Storage:** Strapi's built-in media library or Cloudinary (free tier)

### Development Tools
- **Package Manager:** npm or pnpm
- **Version Control:** Git + GitHub
- **Code Quality:** ESLint + Prettier
- **Type Checking:** TypeScript strict mode

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- PostgreSQL database (local or cloud)
- Git

### Initial Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd flolabsinternational
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.local.example .env.local
   ```
   
   Edit `.env.local` with your values:
   ```env
   # Database
   DATABASE_URI=postgresql://user:password@localhost:5432/flolabs
   
   # Payload CMS
   PAYLOAD_SECRET=your-secret-key-here
   PAYLOAD_PUBLIC_SERVER_URL=http://localhost:3000
   
   # Application System Integration (if applicable)
   APPLICATION_API_URL=your-application-system-api
   APPLICATION_API_KEY=your-api-key
   
   # Optional: Email service for notifications
   SMTP_HOST=smtp.example.com
   SMTP_USER=your-email@example.com
   SMTP_PASS=your-password
   ```

4. **Run database migrations**
   ```bash
   npm run payload migrate
   ```

5. **Create admin user**
   ```bash
   npm run payload seed
   ```

6. **Start development server**
   ```bash
   npm run dev
   ```

7. **Access the application**
   - Frontend: http://localhost:3000
   - CMS Admin: http://localhost:3000/admin

## 🚢 Deployment

### Vercel (Recommended)

1. **Push to GitHub**
   ```bash
   git push origin main
   ```

2. **Import to Vercel**
   - Go to https://vercel.com
   - Import GitHub repository
   - Vercel auto-detects Next.js

3. **Configure Environment Variables**
   - Add all variables from `.env.local`
   - Set `PAYLOAD_PUBLIC_SERVER_URL` to your Vercel domain

4. **Deploy**
   - Vercel automatically deploys on push to main
   - Preview deployments for pull requests

### Database Setup (Production)

**Option 1: Vercel Postgres**
```bash
vercel postgres create
```

**Option 2: Supabase**
1. Create project at https://supabase.com
2. Copy database URL to Vercel env vars
